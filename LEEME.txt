COYOTES UGARTE V1.5 — AVATARES INFANTILES

Se incorporaron los avatares aprobados: coyotito y coyotita con moño rosa, ambos con uniforme Coyotes y proporciones infantiles.
La bitácora y los datos almacenados en tu navegador se conservan: se utiliza la misma clave local que en la versión anterior.

ACTUALIZAR GITHUB
1. Abre tu repositorio coyotes-ugarte.
2. Add file > Upload files. Sube todos los archivos del contenido de esta carpeta, incluidos los dos avatar_*.webp y la carpeta icons.
3. GitHub mostrará archivos existentes para reemplazar. Confirma con Commit changes.
4. Visita la página publicada y actualiza/reabre la aplicación.

PRIVACIDAD: NO subas listas de niños, respaldos JSON ni exportaciones CSV al repositorio público. Los nombres se cargan desde la app, en el dispositivo.
Si la app ya tiene jugadores en un navegador, haz un respaldo JSON antes de actualizar.
