5. Respaldo y exportación

CSV abre en Excel. La copia JSON conserva jugadores, sesiones y observaciones. Al restaurarla se reemplazan los datos guardados en este navegador.

Importante: los datos se guardan solo en este navegador y dispositivo. Si borras sus datos o cambias de computadora, puedes perderlos. Guarda una copia JSON con regularidad. No es una plataforma en línea ni tiene cuentas de usuario.

6. Uso desde el celular

Esta aplicación ya está preparada como web instalable. Para añadirla a la pantalla de inicio, primero debe abrirse desde una dirección HTTPS publicada. Abrir el archivo index.html directamente no permite instalarla como aplicación.

Los datos no se sincronizan entre dispositivos. Cada teléfono o computadora conserva sus propios registros; crea respaldos JSON después de cada entrenamiento.

No publiques listados con nombres completos ni datos de menores. Usa apodos y mantén las copias de seguridad bajo tu control.
